# インフレ病院

数字がどんどんインフレしていく、2人で協力する放置系ゲームです。ブラウザだけで動きます（インストール不要）。

## 遊び方

1. `index.html` をブラウザで開きます（スマホでも遊べます）。
2. 画面下の **「治療」** ボタンを押すと、患者の HP が減ります。
3. 5回治療するごとに **処方** を1つ選べます。処方を重ねると、1回の治療のダメージが大きくなります。強さは処方だけで決まります（レベルはありません）。
4. 患者を倒すと、さらに HP の大きい患者が来ます。**3人** 治療すると結果画面が出ます。
5. 結果画面では、2人が治した量（貢献度）を比べて勝敗が決まります。「もう一度」で最初から遊べます。

オンラインにつながっていないときは、ダミーの相手と一緒に治療します（3秒ごとに相手も治療します）。

## オンライン対戦の手順

1. 2人とも `index.html` を開きます（同じ場所に置いたファイルでも、公開したページでも構いません）。
2. 2人で **同じ合言葉**（1〜24文字。英数字・ひらがな・カタカナ・漢字・`_`・`-`）を決めて、「合言葉」欄に入力します。大文字小文字は区別しません。
3. 「接続」を押します。先に入った人がホスト、あとから入った人が参加者になります。
4. 「接続しました！」と出たら開始です。相手の治療も自分の患者に反映され、貢献度で勝敗を比べます。
5. 切断されると、自動でダミーの相手に戻ります。

注意：
- 「接続」を押すと、PeerJS Cloud（外部の接続仲介サーバー）と通信します。接続しなければ外部には何も送りません。
- 相手から届くデータは検証してから使います。
- 社内ネットワークなどでは P2P 通信がつながらないことがあります。

## テスト

```
node test.js
```

## ファイル

- `index.html` 画面・操作
- `bignum.js` 大きな数の計算と表示
- `prescriptions.js` 処方
- `patient.js` 患者
- `coop.js` 協力・ダミーの相手
- `net.js` オンライン通信（メッセージの検証）
- `result.js` 結果の判定
